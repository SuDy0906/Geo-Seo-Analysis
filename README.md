# GEO · SEO Intelligence

Streamlit workspaces for technical SEO scoring, citation-style readiness proxies, crawl-backed HTML caches, and joined analytics (performance link).

**Run**

```powershell
python -m pip install -r requirements.txt
python -m streamlit run "GEO_&_SEO_Analysis.py"
```

Scrape data is gitignored (`data/fxstreet_scrape/`, `data/site_scrape/`); populate caches from **Sitemap crawler** or **Article index** in the app.
